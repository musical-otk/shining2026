🏠 홈
  • 다음 공연 D-day + 캐스팅·좌석
  • 예정 일정 목록 (설정에서 표시 배역 선택)
  • 쿠폰(40% 할인권) · 재관람카드 현황
  • 최근 관람 이력 + 마일스톤 달성 표시
📅 캘린더
  • 맨 위 배우 | 배역 중 하나를 골라 거른다 (보이는 쪽 선택만 걸리고, 다른 쪽은 기억해 둔다)
  • 배우 → 이름을 누르면 배역 상관없이 그 배우가 나오는 회차 (쉐도우 포함). 여러 명이면 한 명이라도 나오는 회차. 다시 누르면 해제
  • 고른 배우가 쉐도우로만 나오는 회차는 시간이 연하게 보인다
  • 배역 → 프로이트·융·쉐도우 탭 → 배우 선택 → 그 배역으로 나오는 회차만
  • ✅ = 기록한 회차
  • 날짜 클릭 → 회차 목록 + 기록 추가/상세
🎫 쿠폰·재관람카드
  • 7칸 도장판 — 관람 1회당 도장 1개 (첫 관람부터 발급)
  • 3회 달성 → 40% 할인권 1매 (쿠폰 현황에 자동 적립)
  • 5회 달성 → 📸 지정 폴라로이드 1매
  • 7회 달성 → 💿 실황 OST (교환권 없음 · 카드 지참)
  • 할인권종을 "40% 실물할인권 소지자 할인"으로 기록하면 쿠폰이 자동 차감 — 사용기간 12/22~3/7
😌 통계
  • 히트맵 — 좌석 방문 횟수 (B·C·D 구역, 공식 좌석도 배치 그대로 · S석은 점선)
  • 배우별 — 배우 6명 한 표: 본 배역 · 쉐도우 · 합계 (관람 / 전체 회차)
  • 조합별 — 프로이트·융·쉐도우 조합, 행 클릭 시 날짜 목록
  • 지출 — 총 지출 / 평균 티켓가
📝 팁
스케줄 연동 — 날짜 클릭 → 회차 옆 "+ 기록"으로 캐스팅 자동 입력
재관람카드 — 기록 저장 시 도장판 선택하면 자동 도장. 7칸 초과 시 새 카드 자동 생성 (서로 다른 카드 합산 불가)
현장 규칙 — 발급·적립은 MD부스에서 공연 시작 1시간 전 ~ 15분 전, 종료 후 10분. 1회 공연당 1번, 동일 회차·지난 공연 적립 불가
좌석 — 구역(B·C·D) → 열 → 번호 순으로 고르면 티켓 가격 칸에 R석/S석 예시 가격이 보입니다
차액 지불 — 증빙이 필요한 할인(재관람·뉴프로덕션·학생·직장인·장애인/국가유공자 등)을 증빙 없이 쓰면 체크. 40% 할인권이 차감되지 않습니다
양도 — 표는 있었지만 못 본 회차는 "양도"로 표시. 도장·통계·지출에서 빠집니다
사진 첨부 — 원본 화질 저장. 탭: 전체화면 / 두 번 탭: 가로 꽉채움
데이터 백업 — 설정 → JSON 내보내기/가져오기. 사진 포함 옵션 있음
